Add `Intervals(lo, hi)`, an `.oindex` selector for runs of consecutive indices. It selects what `np.r_[lo[0]:hi[0], ...]` does without listing every index, and chunk planning costs per interval rather than per index. `GridPartition.sets` can now hold a new table type, `IntervalSet`, so code that dispatches on `StridedSet` and `IndexedSet` needs a branch for it.
